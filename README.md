# ImageProcessor

Утилита для пакетного удаления фона с картинок (через rembg) и подстановки своего фона. Поддерживает скачивание по ссылкам, обработку локальных файлов, drag-and-drop, CLI и retry для нестабильной сети.

В комплекте две версии. Прежде чем что-то собирать — выбери нужную.

---

## Какую версию выбрать

### CPU-версия (`cpu/`) — для большинства

Подходит **всем без исключения**. Работает на любом компьютере с Windows. Не требует видеокарты NVIDIA, не требует CUDA, не требует ничего кроме самого Python для сборки.

Размер дистрибутива: **~400 МБ**

Скорость: примерно **1–3 секунды на картинку** на современном CPU (Intel i5/i7, Ryzen 5/7).

### GPU-версия (`gpu/`) — только NVIDIA

Подходит **только владельцам видеокарт NVIDIA** с установленным NVIDIA-драйвером и CUDA Toolkit. Использует onnxruntime-gpu — обработка идёт на видеокарте.

Размер дистрибутива: **~800–1200 МБ** (внутри лежат CUDA-библиотеки)

Скорость: примерно **0.1–0.3 секунды на картинку** на RTX 3060 и выше. Это в **~10 раз быстрее** CPU-версии. На больших пачках (500+ картинок) экономия времени становится драматичной.

GPU-версия **сама падает на CPU**, если CUDA не найдена при запуске — окно всё равно откроется и работать будет, но без ускорения. В заголовке окна и в логе будет написано "CPU (CUDA not available)" — это сигнал, что что-то не так с установкой CUDA.

---

## Какие требования у GPU-версии

На машине, где запускается GPU-версия (не сборки, а **пользователя**), должно быть:

1. **NVIDIA-видеокарта** GTX 1060 / RTX 2060 или новее
2. **NVIDIA driver** свежий (минимум 525 для CUDA 12, 470 для CUDA 11.8). Скачать: <https://www.nvidia.com/Download/index.aspx>
3. **CUDA Toolkit** — версия должна совпадать с тем, под что собран onnxruntime-gpu:
   - onnxruntime-gpu **1.17+** требует CUDA 11.8 или 12.x. Скачать: <https://developer.nvidia.com/cuda-downloads>

Без этих компонентов exe откроется, но работать будет на CPU (и тогда нет смысла — лучше взять CPU-версию, она легче).

## Что в каждой папке

```
cpu/
  app.py              — исходник (CPU)
  build.spec          — PyInstaller spec
  build.bat           — сборка одной кнопкой
  requirements.txt    — onnxruntime (CPU)

gpu/
  app.py              — исходник (GPU, с автодетектом CUDA)
  build.spec          — PyInstaller spec
  build.bat           — сборка одной кнопкой
  requirements.txt    — onnxruntime-gpu (GPU)
```

Папки полностью независимы. Можно собирать только одну, можно обе.

---

## Как собрать

Подробная инструкция — в [`README_BUILD.md`](README_BUILD.md).

Кратко:
1. Зайди в `cpu/` или `gpu/`
2. Двойной клик по `build.bat`
3. Готовый exe в `dist\ImageProcessor\` (CPU) или `dist\ImageProcessor_GPU\` (GPU)

---

## Что умеет программа

Полный список фич — в [`README_FEATURES.md`](README_FEATURES.md).

Кратко:
- Drag-and-drop для links.txt и картинок
- AUTO/MANUAL выбор модели (u2net, isnet, birefnet, silueta, isnet-anime)
- Прогресс по этапам (download / process / save)
- Превью последнего результата прямо в окне
- Stop с корректной остановкой
- Retry для скачиваний
- Сохранение настроек между запусками
- CLI-режим для автоматизации
- Настраиваемые воркеры, размеры, retry policy
