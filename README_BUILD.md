# Сборка в .exe

## Перед сборкой — что выбрать

Если ещё не определился — посмотри в [`README.md`](README.md), там расписано какая версия для кого.

CPU-версия собирается из папки `cpu/`, GPU-версия — из `gpu/`. Папки независимы. Можно собрать только одну, можно обе по очереди в разных папках.

## Системные требования (для сборки)

- **Windows 10/11**
- **Python 3.10 / 3.11 / 3.12 / 3.13** — любая работает. Если у тебя уже стоит, например, 3.12 — он и используется. У всех зависимостей есть wheels под все эти версии.
- **~3–5 ГБ свободного места** на CPU-сборку, **~5–8 ГБ** на GPU-сборку (включая venv с библиотеками)
- **Интернет** для `pip install`

## Сборка CPU-версии

1. Зайди в папку `cpu/`
2. Двойной клик по `build.bat`
3. В начале он напечатает, какой именно Python взял — проверь
4. Жди 5–10 минут (первая установка `onnxruntime` тянет ~200 МБ)
5. Готовый exe в `cpu\dist\ImageProcessor\ImageProcessor.exe`

## Сборка GPU-версии

1. Зайди в папку `gpu/`
2. Двойной клик по `build.bat`
3. Жди **10–20 минут** (onnxruntime-gpu тянет ~400 МБ — это нормально, не пугайся)
4. Готовый exe в `gpu\dist\ImageProcessor_GPU\ImageProcessor_GPU.exe`

> **Важно:** на машине, где ты СОБИРАЕШЬ GPU-версию, CUDA Toolkit ставить **не обязательно** — он нужен только на машине пользователя при запуске. PyInstaller просто упакует библиотеки `onnxruntime-gpu` в дистрибутив.

## Что отдавать пользователю

Не один файл, а **всю папку `dist\...\`** целиком. В ней `.exe` плюс все DLL и данные библиотек. Можно заархивировать в zip.

Если очень хочется один файл — открой `build.spec` и переключись в onefile-режим, но запуск каждый раз будет медленнее на 10–30 секунд из-за распаковки во временную папку.

## Что нужно для первого запуска

- **Интернет** — `rembg` скачает ONNX-модели (`u2net.onnx` ~170 МБ и т.п.) в `%USERPROFILE%\.u2net\` при первом использовании каждой модели. Дальше работает офлайн.
- Файл `links.txt` в формате:
  ```
  artist_name:
  https://example.com/img1.jpg
  https://example.com/img2.jpg
  another_artist:
  https://example.com/img3.jpg
  ```
  Или просто перетащи картинки прямо в окно.
- Фоновая картинка (любой формат, который умеет Pillow).

Для **GPU-версии** дополнительно на машине пользователя:
- NVIDIA driver (525+ для CUDA 12, 470+ для CUDA 11.8)
- CUDA Toolkit 11.8 или 12.x

Если что-то из этого отсутствует — exe всё равно откроется, но в логе будет "CPU (CUDA not available)" и скорость как у CPU-версии.

## Если сборка падает

| Симптом | Что делать |
|---|---|
| `pip install` падает на onnxruntime | Обнови pip: `python -m pip install --upgrade pip`. Если всё равно нет колеса — поставь рядом 3.12 и используй его. |
| `pip install` падает на **onnxruntime-gpu** | Возможно у тебя 32-битный Python. Поставь 64-битный: <https://www.python.org/downloads/windows/> |
| `pyinstaller` ругается на `tkinterdnd2` | Обнови: `pip install -U tkinterdnd2 pyinstaller` |
| exe запускается, но окно мгновенно закрывается | Временно поставь в `build.spec` `console=True`, пересобери, увидишь traceback |
| `Failed to load DLL` про onnxruntime | Антивирус сожрал DLL. Добавь папку `dist\...\` в исключения Windows Defender |
| GPU-версия пишет "CUDA not available" | На целевой машине нет драйвера или CUDA Toolkit. См. раздел "Что нужно для первого запуска" |
| Очень большой размер | Норма: CPU ~400 МБ, GPU ~800–1200 МБ. UPX не помогает — ломает onnxruntime |

## Запуск без сборки (для отладки)

```cmd
cd cpu        REM или cd gpu
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

## Несколько Python-версий на одной машине

Если у тебя стоит и 3.11 и 3.12 и нужно собрать конкретной — отредактируй первую строку `build.bat`:

```bat
REM было:
python -m venv venv

REM стало (например, для 3.11):
py -3.11 -m venv venv
```
